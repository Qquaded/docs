## Description

The Settings API provides a comprehensive client-side settings management system for Construct. It handles UI theming, keybindings, animations, and appearance settings through a reactive environment value system integrated with LuaCSS.

## Accessing Settings

The Settings API is available through the Construct API:

```lua
local ConstructAPI = require(ReplicatedStorage.Shared.Locations)
local settings = ConstructAPI:Get("SettingsClient")
```

## Settings Categories

### Animations

Animation configuration for UI transitions and effects.

```lua
local animations = settings.Animations

print(animations.Damping)   -- Default: 1
print(animations.Frequency) -- Default: 5
```

**Properties:**
- `Damping` (number): Spring damping coefficient
- `Frequency` (number): Spring oscillation frequency

### Keycodes

Keyboard and input bindings for various actions.

```lua
local keycodes = settings.Keycodes

-- Available key bindings
print(keycodes.Copy)        -- {LeftControl, C}
print(keycodes.Paste)       -- {LeftControl, V}
print(keycodes.Placing)     -- {MouseButton1}
print(keycodes.Rotate)      -- {R, T, Y}
print(keycodes.Delete)      -- {MouseButton1}
print(keycodes.BuildMenuKeycode)   -- {One}
print(keycodes.LaunchKeycode)      -- {Five}
```

### Appearance

Comprehensive theming and visual settings.

```lua
local appearance = settings.Appearance

-- Colors
print(appearance.BackgroundColor)           -- Theme-based background
print(appearance.PrimaryButtonColor)        -- Primary button color
print(appearance.SecondaryButtonColor)      -- Secondary button color
print(appearance.ErrorColor)                -- Error state color
print(appearance.SuccessColor)              -- Success state color

-- Typography
print(appearance.Font)                      -- Default: BuilderSans
print(appearance.TextSize)                  -- Default: 24
print(appearance.SecondaryTextSize)         -- Default: 18
print(appearance.CaptionTextSize)           -- Default: 14

-- Layout
print(appearance.TopbarYSize)               -- Default: 50
print(appearance.CornerRadius)              -- Default: {Scale=0, Offset=15}
print(appearance.Resolution)                -- Default: "16:9"
```

### Client Plugins

Container for client-side plugin configurations.

```lua
local plugins = settings.ClientPlugins
-- Plugin configurations are stored here
```

### Metadata

Read-only information about the client configuration.

```lua
local metadata = settings.Metadata

print(metadata.Version)     -- Client version
print(metadata.SyncType)    -- Rojo sync type

-- Theme information
local themeInfo = metadata.Theme
print(themeInfo.ThemeVersion)
print(themeInfo.AccessibilityScore)
```

## Reactive Environment Values

The Settings API integrates with LuaCSS to provide reactive theming:

```lua
local luacss = require(ReplicatedStorage.Shared.Libraries.luacss)

-- All settings are available as reactive environment values
local primaryColor = luacss.getEnvValue("PrimaryButtonColor")
local textSize = luacss.getEnvValue("TextSize")

-- Values update automatically when settings change
local button = luacss.compileObject({
    class = "TextButton",
    BackgroundColor3 = primaryColor,
    TextSize = textSize,
    Text = "Themed Button"
})
```

## Theme Integration

The settings system includes a comprehensive theme generated by the ThemeService:

```lua
local themeUtils = shared.ThemeUtils

-- Access the full theme object
local theme = themeUtils.Theme

-- Theme utility functions
local contrastText = themeUtils.GetContrastText(Color3.new(0.2, 0.2, 0.2))
local mixedColor = themeUtils.MixColors(Color3.new(1, 0, 0), Color3.new(0, 1, 0))
local contrastRatio = themeUtils.GetContrastRatio(Color3.new(0, 0, 0), Color3.new(1, 1, 1))

-- Validate contrast ratios
local validation = themeUtils.ValidateContrast(Color3.new(0, 0, 0), Color3.new(1, 1, 1))
print(validation.passesAA)  -- true if contrast ratio >= 4.5
```

## Modifying Settings

Settings can be modified through the shared API:

```lua
-- Get the settings API
local settingsAPI = shared.SettingsAPI

-- Modify a setting
settingsAPI:Set("CustomSetting", "value")

-- Retrieve a setting
local value = settingsAPI:Get("CustomSetting")

-- Access reactive environment values
local envValue = settingsAPI.CustomSetting
```

## Key Bindings

The Settings API provides access to key binding configurations:

```lua
local SettingsKeycode = require(ReplicatedStorage.Shared.Classes.SettingsKeycode)

-- Create key bindings from settings
local buildMenuKey = SettingsKeycode.new(
    unpack(settings.Keycodes.BuildMenuKeycode)
)

local launchKey = SettingsKeycode.new(
    unpack(settings.Keycodes.LaunchKeycode)
)

-- Use the key bindings
buildMenuKey:InputBegan(function()
    openBuildMenu()
end)

launchKey:InputBegan(function()
    launchCurrentBuild()
end)
```

## Animation Settings

Configure UI animation behavior:

```lua
-- Apply animation settings to LuaCSS
luacss.springSettings(
    settings.Animations.Damping,
    settings.Animations.Frequency
)

-- Create animated UI elements
local panel = luacss.compileObject({
    class = "Frame",
    Size = UDim2.fromScale(0.5, 0.5),
    BackgroundColor3 = luacss.getEnvValue("BackgroundColor"),
})

-- Animate the panel
luacss.spring(panel, {
    Size = UDim2.fromScale(0.8, 0.8)
})
```

## Accessibility Features

The settings system includes accessibility compliance information:

```lua
-- Check accessibility compliance
if settings.Appearance.AccessibilityCompliant then
    print("Theme meets AA accessibility standards")
end

print("Accessibility Score:", settings.Appearance.AccessibilityScore)
```

## Default Settings Structure

```lua
{
    Animations = {
        Damping = 1,
        Frequency = 5,
    },

    Keycodes = {
        Copy = {Enum.KeyCode.LeftControl, Enum.KeyCode.C},
        Paste = {Enum.KeyCode.LeftControl, Enum.KeyCode.V},
        -- ... more key bindings
    },

    ClientPlugins = {},

    Appearance = {
        -- Colors, fonts, sizes, etc.
        BackgroundColor = Color3,
        PrimaryButtonColor = Color3,
        Font = Enum.Font,
        TextSize = number,
        -- ... comprehensive theming
    },

    Metadata = {
        Version = "v6.1",
        SyncType = "Rojo",
        Theme = {
            ThemeVersion = string,
            AccessibilityScore = number,
            -- ... theme metadata
        }
    }
}
```

## Integration with Mods

Mods can access and extend the settings system:

```lua
local ConstructAPI = require(ReplicatedStorage.Shared.Locations)
local settings = ConstructAPI:Get("SettingsClient")

-- Create mod-specific settings
local modSettings = {
    enabled = true,
    volume = settings.Animations.Frequency, -- Use existing settings
    customColor = settings.Appearance.PrimaryButtonColor,
}

-- Register mod settings
ConstructAPI:Register("MyModSettings", modSettings)

-- Use in mod UI
local modButton = luacss.compileObject({
    class = "TextButton",
    BackgroundColor3 = luacss.getEnvValue("MyModSettings.customColor"),
    Text = "Mod Button"
})
```

## Notes

- Settings are reactive and update UI automatically through LuaCSS
- All color values are theme-generated and accessibility-compliant
- Key bindings support both single keys and key combinations
- Animation settings affect all LuaCSS spring animations
- The theme system ensures consistent visual design across the application
